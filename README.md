## 设计篇的关键假设

- **参考而非复刻**:以 Foundry 的公开概念与行为为参考,设计通用本体平台。
- **技术栈可替换**:参考栈为 PostgreSQL、Kafka、OpenSearch、ClickHouse、Redis、S3、Kubernetes;文中标注可替换点。
- **平台不是数仓**:负责业务语义、受控写回与治理;存储与批处理仍由现有数据平台承担。
- **多租户与 AI 优先**:隔离、配额、审计、工具授权从第一天纳入设计。
- **数值是设计目标**:规模、延迟、SLO 用于推演架构,需按真实业务校准。
